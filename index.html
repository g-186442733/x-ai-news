Grok Bot 是什么

  • 三层架构：Jarvis（云端主控 Bot）→ Vision（Linux 云主机）→ Friday（本地 Mac 工作站）
  • DN-B 编排：Driver = dsh / deepseek-flash（effort max）；Navigator = Codex CLI gpt-6-astra（长流程 -p max）
  • 审代码优先 Codex CLI（档位 ≥ 编程任务），Paseo 审查代理兜底
  • 内置 X 公开读：搜帖 / 用户帖 / 新闻 / 趋势（无需自备开发者密钥）
